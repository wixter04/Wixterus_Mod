This Repo is the full source code of the mod "Wixterus" for the game "Minecraft" loaded with the FML (Forge Mod Loader)

The Wixterus Mod Adds a new ore to the game named "wixterus" that can be found in caves like a normal ore or in a few of the mod's structures that are added in every update.With the Wixterus you can craft an armor that is better than the nethirite armor and tools that are more efficient than the netherite and diamonds ones. 

The mod is available in both [Modrinth](https://modrinth.com/mod/wixterus) and [Curse Forge](https://www.curseforge.com/minecraft/mc-mods/wixterus) websites

Please keep in mind that this mod is very experimental (I am still learning mod creation) if you have any comments or feedbacks for the mod you're welcome to keep a comment either on the mod's pages or on this repo.
