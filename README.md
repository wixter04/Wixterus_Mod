This is a Repo of the mod "Wixterus" that was made for the game "Minecraft" 

The Wixterus Mod Adds a new ore to the game named "wixterus" that can be found in caves like a normal ore or in a few of the mod's structures that are added in every update.  With the Wixterus you can craft an armor that is better than the nethirite armor and tools that are more efficient than the netherite and diamonds ones.

This mod is available on both modrinth and curseforge these are their link :
